# ReRun LITE 1.0.0 - the first release

ReRun LITE is a small Windows app that farms the Crest Palace in Grand Summoners for you through BlueStacks. It does
one job (Auto Crest) and has a nicer window than its big sister, ReRun. It is its own project: its own version number,
its own releases, and it does not need ReRun installed.

**Please read first:** Grand Summoners may not allow macros, bots or automation. Using this can lead to account limits,
suspension or a permanent ban. The warning is on the Auto Crest tab all the time. Use it at your own risk.

## What it does

- **Auto Crest.** Starts a Crest Palace quest on Auto-Loop, looks at each crest it gets, scraps the ones you do not
  want and stops (and tells you on Discord, if you set that up) when one you do want drops. It can run 24/7 and
  recover from a game crash.
- **A daily palace picker.** Tell it which palace to run on each day of the week (or cycle through a list) and it
  opens only that palace, using a picture of it. The day changes at the game's reset (6 AM UTC-6), not at your PC's
  midnight. If today's picture is missing, or the palace is not on the screen, it stops and says which palace and
  which file. It never runs a different palace by itself. You can import all the palace pictures from GS Companion.
- **Tabs:** Auto Crest, History (what was kept and scrapped), Templates (the small pictures it looks for), Settings
  (Crest, the palace picker, Discord alerts, general options, the log).
- **Everyday helpers:** a Start/Stop button and Ctrl+Enter, a status chip that says what it is doing, a "needs setup"
  strip that tells you what is missing, keyboard shortcuts, Pin on top, a sound on alerts (off by default), and it
  remembers your window, tab and emulator.
- **Bring your data over.** On a first start it can copy your settings, stats, crest log, History and key from an older
  ReRun. It shows only the most recent data; older folders wait in an "Older data" drop-down.
- **A start-up progress bar** with "about N s left", so you can see it is working.

## How it looks

Nine themes (Settings > General > Theme): **Ahri** (the default), **Midnight**, **Sakura** (a light one), **Ember**,
**Aurora** and **Neon**, plus ReRun's own **Dark**, **Light** and **Automatic**. Each of the six LITE themes has its own
looping video playing behind the window (original animations, not game art). You can use your own video for Ahri: drop
a file into the `background` folder. A small video (like a GIF) is cleaned up and enlarged once so it stays sharp, and
buttons and text sit on a softened patch of the video so they stay crisp. You can switch the video off, dim it, or lower
its frame rate in Settings > General > Background.

## How to install and start

1. Download `RerunLite-1.0.0.zip` below and unzip it anywhere (its own folder is best).
2. Run `RerunLite.exe`. The first start takes a few seconds while it unpacks.
3. Enter your key when it asks. The same key that works in ReRun works here.
4. In BlueStacks turn on ADB (Settings > Advanced) and set the display to 1280 x 720.
5. Add your emulator on the Auto Crest tab (Detect BlueStacks, or Add), then set the palace: either in Settings > Palace
   Selector, or by capturing the palace tile in the Templates tab.

## What has and has not been tested

- **Tested by computer:** about 50 automatic tests pass. They run Crest against a simulated game (scrap and redeploy,
  keep and stop, unknown crest, dry run), the palace picker (day changes at the reset, weekday and cycle, never opening
  another palace, imports never overwrite your files), the video background (plays behind the window, follows it,
  maximises, ignores clicks), the themes, the enlarging of small videos, the import window, the progress bar, and
  starting the program again after a theme change.
- **Not tested on the real game:** ReRun LITE as a whole has not been run against a live BlueStacks window. The Crest
  script itself is the one that was checked live in ReRun.
- **Not done yet:** the in-app "Check for updates" has nothing to find, because no LITE update has been published.
  The exe is not code-signed, so Windows Defender or SmartScreen may warn about it.
- **Needs:** Windows 10 or 11, BlueStacks 5 with ADB turned on. A key is required to sign in.

## Fixed while building this release

- Clicking the background used to hide every button until you clicked the window again. It no longer does.
- Changing the theme used to crash the exe on restart. It now restarts cleanly.
- Text and rounded buttons on top of the video used to look ragged, with dark dots on the corners. They are now crisp.
