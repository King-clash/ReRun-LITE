# ReRun LITE 1.3.0

## New in 1.3.0

- **16 anime themes.** Jujutsu Kaisen, Solo Leveling, Naruto Akatsuki, Bleach, Evangelion, Demon Slayer, One Piece, Attack on
  Titan, Chainsaw Man, Frieren, Cowboy Bebop, Tokyo Ghoul, Hunter x Hunter, Initial D, Dragon Ball and Spy x Family. Pick one
  in Settings > Appearance. Each has its own colours (checked so text stays readable) and its own looping background, drawn
  for ReRun LITE in a hand-drawn style: hard edges, no blur, and motion that changes every other frame instead of gliding.
  The backgrounds are original animation; they use no artwork from any show.
- **Anime artwork.** Settings > Artwork lists 16 collections and shows your pictures in five places: the window
  background, the header, the instance portrait, the side panel strip and the gallery preview. Picking an anime theme also
  picks that anime's collection. Nothing is bundled: add your own pictures (or import a whole folder) and they are kept on
  your PC. Changing artwork never interrupts a running Crest, and never replaces the live BlueStacks video.
- Everything else is as in 1.2.0.

## How to install and start

1. Download `RerunLite-1.3.0.zip` below and unzip it anywhere (its own folder is best).
2. Run `RerunLite.exe`, enter your key, and add your emulator on the Auto Crest tab.
3. The exe is not code-signed, so Windows SmartScreen or Defender may warn.
4. Grand Summoners may not allow automation, and using it can get an account limited or banned.

## What has and has not been tested

- **Tested by computer:** the automatic tests for the theme palettes (readable text, a video and an artwork collection for
  each), the artwork library and the artwork windows.
- **Not tested on the real thing:** the 16 background videos were checked as still frames, not watched playing in the
  window on Windows; the themes were not tried on the real game; the exe was built on a Windows build server, where its own self-test (it opens the whole window once) and the check for
  personal files passed, but nobody has run it on a real PC yet.
- **Not in this version:** the animated header effects and the per-show fonts from the design mock-up.
