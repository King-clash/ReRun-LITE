# ReRun LITE 1.2.0

## New in 1.2.0

- **It finds your older versions and asks if you want them gone.** Every new version arrives as a zip you unzip into a new
  folder, so old ones pile up (your Downloads can hold several copies of 150 MB each). About 12 seconds after it starts,
  ReRun LITE looks in the folder it sits in, the folder above it, Downloads, Desktop and Documents (up to three folders
  deep) for **older copies of itself**, both unzipped folders and downloaded zips, and if it finds any, a window lists them
  with their version, size and place. You choose; nothing is removed without a second confirmation.
- **Safe by design.**
  - Only copies **older** than the one running are listed. The running copy, and anything around or inside it, is never listed.
  - A folder is only listed if it holds `RerunLite.exe`, so a folder that is merely named alike is left alone. Source
    checkouts (anything with a `.git`) are never touched.
  - Everything goes to the **Recycle Bin**, never a permanent delete, so a mistake can be undone.
  - A copy that holds your own data (settings, stats, History, key) is marked "Holds your own data" and left **unticked**.
    The window says so again in the confirmation if you tick it anyway.
  - **Don't ask again** remembers those copies; a newly downloaded version that becomes old later is asked about once.
- **Ask any time:** Settings > General > Window & files > **Older versions: Find…**, or Ctrl+K and type "old versions".
- Everything else is as in 1.1.2.

## How to install and start

1. Download `RerunLite-1.2.0.zip` below and unzip it anywhere (its own folder is best).
2. Run `RerunLite.exe`, enter your key, and add your emulator on the Auto Crest tab.

## What has and has not been tested

- **Tested by computer:** the automatic tests pass, including new ones that build a fake pile of old copies and check what
  is listed (older folders and zips, wrapped and unwrapped), what is not (the running copy, newer versions, a folder
  without the exe, source checkouts, other folders named alike), that the running copy can never be removed, that a refused
  copy never reaches the Recycle Bin call, that declining the confirmation removes nothing, and that "Don't ask again" is
  remembered. A scan of this PC's real Downloads found the right four older copies in under a second.
- **Not tested on the real thing:** a real removal of an old ReRun LITE folder through the window (the tests use a stand-in
  for the Recycle Bin call, and send one tiny folder made for the test through the real Recycle Bin).
