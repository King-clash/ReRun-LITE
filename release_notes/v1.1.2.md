# ReRun LITE 1.1.2

## Fixed in 1.1.2

- **Crest now gets past the Equip Crest screen that has a "Confirm" button.** If a crest was already waiting in the game
  when Crest started (it dropped before the script began), the game shows the Equip Crest screen with **Confirm** where
  the usual screen has OK and Redeploy. Crest only knew how to press OK, so it looked at the same crest again and again
  (your log showed "Same lv3 crest as before" over and over). Now, when neither Redeploy nor OK is on the screen, Crest
  reads the words on the screen, finds **Confirm**, taps it, and then taps the "OK" on the scrap confirmation that follows.
  It reads the word, not a picture of the button, so it needs no captured template.
- **It can no longer loop for ever.** If the same crest still will not clear, the third try saves a picture of the screen
  (in the `debug` folder, ending `_equip_crest_stuck.png`) and looks for OK more loosely; the fifth try stops and tells
  you (log and Discord) instead of repeating. If that ever happens, send me that picture.
- Everything else is as in 1.1.1.

## How to install and start

1. Download `RerunLite-1.1.2.zip` below and unzip it anywhere (its own folder is best).
2. Run `RerunLite.exe`, enter your key, and add your emulator on the Auto Crest tab.

## What has and has not been tested

- **Tested by computer:** the automatic tests pass, including two that run Crest against a simulated game with a
  drawn "Confirm" button and the real text reader: Crest finds the word, taps it, taps the confirmation and moves on;
  and when there is no button at all it stops with a message after five tries. The text reader found "Confirm" in a
  drawn button, and did not mistake "OK" or "Redeploy" for it.
- **Not tested on the real game:** the Confirm button in the real game is not pictured anywhere I could read, so the test
  uses a drawn one. If the game's own lettering is read less well than my drawn one, the stuck-screen picture and the
  stop-after-five-tries safeguard will tell us. It also assumes a scrap confirmation OK follows the Confirm tap.
