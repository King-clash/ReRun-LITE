# ReRun LITE 1.1.1

## Fixed in 1.1.1

- **Crest no longer stops with "quest row not recognised".** After opening the day's palace, Crest looks at the list of
  quests (for example "The Subject in Trance" in PRO, ADV and INT). The old code only knew how to pick one if you had
  saved a picture of that exact quest, which only fits one palace, so on any other day it gave up. Now, when there is no
  picture and no quest name set, it opens the **top quest on the list** (the hardest one, listed first) and says so in
  the log. If you want a different one, type part of its name (for example `ADV`) in Settings > Auto Crest > Getting to
  the palace > *Quest to farm*; a name you set, or a picture you captured, still wins.
- Everything else is as in 1.1.0.

## How to install and start

1. Download `RerunLite-1.1.1.zip` below and unzip it anywhere (its own folder is best).
2. Run `RerunLite.exe`, enter your key, and add your emulator on the Auto Crest tab.
   Your settings stay in the folder you already use; copy the new exe over the old one, or use "Import" on first start.

## What has and has not been tested

- **Tested by computer:** the automatic tests pass, including a new one for this fix (opens the top quest when nothing
  else applies; still lets a quest name, a captured picture, or a single-quest list decide).
- **Not tested on the real game:** the fix is built from the log and screenshot of a real failed run (Sunday, Shrine of
  Discordia, three quests listed). It has not been run through a full farming loop yet.
